# Feature 05: Adhoc Session Creation

## Overview
Enables organizers to quickly spin up pop-up, one-off, or casual badminton sessions without requiring a pre-configured weekly schedule.

## User Stories
- **As a Session Manager**, I want to launch an instant adhoc session with custom rules and courts so that casual games or pop-up sessions can start immediately.

## Key Functional Specifications

### 1. Adhoc Session Wizard
- **Session Name**: Customizable title (e.g. "Friday Pop-up Tournament").
- **Target Winning Score Options**: Quick-select buttons for `11`, `15`, `21`, or `30` points.
- **Game Type Selection**: `DOUBLES`, `SINGLES`, `MIXED_DOUBLES`, or `MULTI_TYPE`.
- **Court Count**: Select initial active courts (e.g., 2 to 8 courts).

### 2. Player Selection & Initialization
- **Member Pool Check-in**: Multi-select modal to check in attending club members.
- **On-the-Fly Guest Addition**: Quick-add guest players directly during session initialization.
- **Instant Launch**: Immediately transitions to the Live Session view with courts active and players queued.
